# Ejercicio 2.1

## Apartado 1

- MVP: En este caso el MVP tendria todas las funcionalidades que tiene el primer prototipo funcional creado por Tálamo entregado a Ardana y que se esta empezando a usar y a validad, pero que esta sujeto a cambios y a externder su funcionalidad. Las funcionalidades seran: dar de alta obras, registrar tareas y asignarlas a personas. Servira para que empieze a funcionar y validar que el producto es correcto.
- MVE: En este caso para el MVE tendríamos que hacer funcional el prototipo estático añadiendo las funcionalidades del MVP, una vez añadidas se debe de validar con el cliente, pero todavia no es el producto final.
- MAP: Para el MAP necesitamos alguna funcionalidad inovadora que no sea común ver en aplicaciones por el estilo
